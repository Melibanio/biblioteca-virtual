Sobre o projeto

A Biblioteca Virtual é um projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas. Nesta primeira versão os dados ficam salvos no próprio navegador. O cadastro dos livros é feito pelo administrador, em uma página separada e protegida por login.
